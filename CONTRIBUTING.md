# Contributing

Thanks for your interest in evidence-dev-skills.

- Issues: report wrong or outdated guidance with the skill name, the Evidence.dev version, and
  what the agent produced versus what you expected.
- Pull requests: fork, branch from `main`, and keep each change to one skill where possible.
  Every skill lives at `skills/<name>/SKILL.md` with `name` and `description` frontmatter.
- Before submitting, run `python3 scripts/validate_skills.py`.
- Security reports: see SECURITY.md. Do not open public issues for vulnerabilities.
